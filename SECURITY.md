# Security Policy

This project follows the BigRangaTech community-wide Security Policy.

Read the full document here:
https://git.bigrangatech.com/Ranga/community/-/blob/main/SECURITY.md

To report a security vulnerability, send an encrypted email to bdfl@bigrangatech.com with the subject line "Security Vulnerability Report".

Operator security for a running KeyStone install (sessions, Docker socket, System Manage) is in [docs/src/security.md](docs/src/security.md), also at `/help/security` on the UI.
